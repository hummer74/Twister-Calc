# Расчёт теплообменников на витых трубах

Десктопное приложение для ОС Windows (Python 3.10+) для автоматизированного
расчёта, анализа и оптимизации кожухотрубных теплообменников с витыми
эллиптическими трубами. Реализует сквозной цикл: парсинг отчётов HTRI
(PDF, формы Т-1/Т-2/Т-3) → верификация данных в GUI → теплогидравлический
расчёт → оптимизация геометрии витой трубы → экспорт отчётов (PDF/XLSX/JSON).

## Быстрый старт (для инженера)

1. Установите Python 3.10 или новее с https://www.python.org
   (при установке отметьте галочку «Add Python to PATH»).
2. Запустите `start.bat` двойным щелчком. Скрипт сам создаст виртуальное
   окружение, установит зависимости и запустит программу.
3. В программе: вкладка «Исходные данные» → «Загрузить PDF (HTRI)»,
   проверьте/отредактируйте данные в таблице → вкладка «Расчёт» →
   «Оптимизация» → «Графики» → «Экспорт».

## Возможности

- **Парсинг отчётов HTRI** (pdfplumber + PyMuPDF): температуры, расходы
  (в т.ч. по фазам — пар/жидкость), теплофизические свойства, геометрия,
  ограничения по потерям давления и расчётному давлению. Нераспознанные
  поля помечаются для ручного ввода.
- **Расчётное ядро**: d_e, Re, Pr, Nu, h, f, ΔP, LMTD, U.
  Турбулентный режим — корреляции Yang et al., 2011
  (DOI: 10.1016/j.applthermaleng.2011.05.030); ламинарный режим —
  корреляции гладкой трубы с множителями витой геометрии
  (TODO: заменить на ламинарные корреляции Yang et al. при получении
  первоисточника); переходная зона — интерполяция с предупреждением.
- **Среды**: мазут и нефть (справочные таблицы с интерполяцией по
  температуре; значения из отчётов HTRI имеют приоритет). Поддержка
  двухфазного потока (жидкость + пар): гомогенная модель или множитель
  Локхарта–Мартинелли.
- **Оптимизация** (scipy): подбор соотношения осей a/b и шага скрутки S
  для максимизации Pf = (h/h_ref)/(ΔP/ΔP_ref) с ограничениями по ΔP
  из отчёта HTRI; дополнительно вычисляется PEC.
- **Экспорт**: PDF (сводный отчёт с графиками и пояснительной запиской),
  XLSX (расчётные таблицы и векторы итераций), JSON (снапшот проекта
  для повторной загрузки).

## Структура проекта

```
main.py                     точка входа
start.bat                   автозапуск (создание venv + установка + запуск)
requirements.txt            зависимости
src/twisted_tube_calc/
  models/                   доменные модели (dataclass)
  fluids/                   свойства мазута/нефти, двухфазные смеси (data/*.csv)
  core/                     расчётное ядро (корреляции, гидравлика, теплота)
  parsers/                  парсер отчётов HTRI
  optimizer/                оптимизация геометрии (scipy.optimize)
  viz/                      графики Matplotlib, генератор пояснительной записки
  exporters/                PDF / XLSX / JSON
  gui/                      интерфейс CustomTkinter
tests/                      pytest + эталонные PDF (fixtures/)
assets/                     шрифты для PDF-отчётов
```

## Ограничения модели

- Корреляции Yang et al. (2011) валидны при Re ≈ 6000–50000 (турбулентный
  режим, вода). При Re > 50000 программа выдаёт предупреждение
  (экстраполяция); при Re < 2300 используются ламинарные корреляции.
- Двухфазный поток: корреляции статьи применяются к свойствам смеси
  (гомогенная модель) или с множителем Локхарта–Мартинелли — статья
  двухфазный режим не охватывает.
- Гидравлика межтрубного пространства (пучок витых труб в кожухе) не
  моделируется: ΔP shell принимается из отчёта HTRI.
