# AGENTS.md — проект «Расчёт теплообменников на витых трубах»

## Контекст
- ТЗ: `TZ.txt` (из `/workspace/TZ_TwistedTubeCalc.pdf`); план: `.agents_tmp/PLAN.md`.
- Эталонные отчёты HTRI: `/workspace/T-1.pdf`, `T-2.pdf`, `T-3.pdf` → скопированы в `tests/fixtures/`.
- Статья корреляций: Yang et al. (2011), DOI: 10.1016/j.applthermaleng.2011.05.030 (`/workspace/Статья.pdf`).

## Сборка/запуск/тесты
- Запуск: `python main.py` (GUI CustomTkinter, требует дисплей; в sandbox — `xvfb-run -a python3 main.py`).
- Тесты: `python -m pytest` (45 тестов, ~3 c). pytest.ini задаёт `pythonpath = src`.
- Зависимости: `pip install -r requirements.txt`.

## Архитектура и ключевые решения
- Пакет `src/twisted_tube_calc/`: models (dataclass) → fluids → core → parsers → optimizer → viz → exporters → gui. GUI не зависит от математики напрямую.
- Все величины в СИ внутри моделей (давление Па, расход кг/с); парсер/GUI конвертируют.
- Геометрия витой трубы: полуоси a,b; сохранение площади сечения круглой трубы (a·b=(d_i/2)²); периметр эллипса — Рамануджан II; d_e = 4A_c/P_c.
- Парсер HTRI — координатный (pdfplumber, слова с x/top): колонки shell/tube калибруются по строкам с 4 числами; пары «пар/жидкость» сливаются только если близко по x (<60 pt), иначе «1680 / 2180» — разные колонки. Блок «Расчётные параметры» имеет свои 2 колонки — там значения по порядку слева-направо.
- Корреляции: турбулентные Yang 2011 (Re 6000–50000); ламинарные — Зидер-Тейт × множитель (TODO: заменить на ламинарные Yang et al., первоисточник не получен); переходная зона 2300–6000 — лог-линейная интерполяция + warning.
- Двухфазный режим: свойства смеси по x (гармоническое), ΔP — гомогенная модель или Локхарт–Мартинелли (выбор в GUI).
- Свойства мазута/нефти: справочные CSV в `fluids/data/` (узлы из отчётов HTRI, вязкость экстраполирована по Андраде); спарсенные значения имеют приоритет.
- PDF-экспорт: reportlab + шрифты `assets/DejaVuSans*.ttf` (кириллица; fallback — системные пути Linux/Windows).
- Оптимизатор: scipy differential_evolution (a/b, S) → макс. Pf; недопустимые по ΔP конфигурации отбрасываются; итерации логируются для XLSX.

## Известные ограничения
- ΔP межтрубного пространства не моделируется — берётся из отчёта HTRI.
- Оптимум по корреляциям Yang монотонно растёт при уменьшении S и a/b → упирается в границы (настраиваются в GUI).
