2.2. Расчетное ядро (Математическая модель)
Модуль должен реализовывать формулы для эллиптических и витых труб, опираясь на научную
базу (материалы статьи). Ключевые расчетные соотношения:

Гидравлический диаметр:

Dh = 4 · Act / Pm
Площадь свободного прохода эллиптической трубы:

Act = π · a · b / 4
Число Рейнольдса (для трубного пространства):

Re = ρ · u · Dh / μ
Общий коэффициент теплопередачи:

U = (Qh + Qc) / (2 · A · ΔTlm)
Также алгоритм вычисляет число Нуссельта (Nu) с учетом шага скрутки и соотношения осей
эллипса, а также потери давления (ΔP).

2.3. Модуль многокритериальной оптимизации
Автоматический подбор параметров витой трубы (угол скрутки, шаг, соотношение осей a/b) для
максимизации фактора производительности теплообменника. Оптимизатор использует методы
поиска условного экстремума.

Целевая функция и Динамические ограничения
Максимизация фактора эффективности:

Pf = (h / href) / (ΔP / ΔPref) → max
Ограничения (извлекаются из PDF):

ΔPshell ≤ ΔPshell_max (Межтрубное пространство)
ΔPtube ≤ ΔPtube_max (Трубное пространство)

Алгоритм отбрасывает конфигурации геометрии, приводящие к превышению допустимых
значений гидравлического сопротивления, найденных в исходных файлах (Т-1, Т-2, Т-3).

3. Требования к архитектуре и стеку технологий
• Язык и Платформа: Python 3.10+, ОС Windows.
• Графический интерфейс: CustomTkinter (современный плоский дизайн) или PyQt6.
• Парсинг PDF: pdfplumber / PyMuPDF (fitz) (высокая точность работы с табличными
данными отчетов HTRI).
• Вычисления и Оптимизация: numpy, scipy.optimize.
• Работа с файлами: pandas, reportlab (или аналоги), встроенный json.

4. Автоматизация развертывания (Start.bat)
Для бесшовного запуска приложения на ПК инженера без навыков программирования создается
сценарий start.bat. Алгоритм его работы:
@echo off
echo [INFO] Проверка наличия Python...
python --version >nul 2>&1
if %errorlevel% neq 0 (
echo [ERROR] Python не установлен!
pause
exit /b
)
echo [INFO] Проверка виртуального окружения...
if not exist venv (
echo [INFO] Создание venv...
python -m venv venv
)
echo [INFO] Активация окружения и установка зависимостей...
call venv\Scripts\activate
pip install -r requirements.txt
echo [INFO] Запуск программы...
python main.py
pause
